Sunset Bay: a complete open-world crime game in the browser — a sun-soaked 3D city to explore on foot and by car, with traffic, pedestrians, car theft, police chases, missions and a story. Built with three.js, no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static file server and open `index.html`.

## The game

You are Milo Reyes, a wheelman back in Solmar City after a job gone wrong. Work your way up through Lena Cruz's garage, Theo Adeyemi's fixes and Rosa Delgado's dock jobs across six story missions, or just cruise the city: steal cars, outrun the police, collect sunset tokens and find trouble.

- A procedural 3D city: Downtown towers, the Marina beachfront, Old Town, the Harbor docks and the Hills villas
- On foot and by car, with traffic, pedestrians, and cars to steal
- A wanted system with police on foot, in cars, and (at five stars) a helicopter
- Combat on foot: fists, pistol, SMG
- Six story missions plus hidden collectibles, a HUD with a minimap, and a save that persists in the browser
- Synthesized sound: engine, sirens, gunshots and a synthwave radio loop — no audio files

## Controls

| Key | Action |
| --- | --- |
| W A S D / arrows | Move / drive |
| Shift | Sprint |
| Space | Jump (on foot) / handbrake (in car) |
| E | Enter / exit car |
| Mouse | Aim (right-drag orbits the camera) |
| Left click | Shoot / punch |
| Right mouse (hold) | Aim |
| R | Reload |
| 1 / 2 / 3 | Weapons |
| H | Horn |
| N | Music on/off |
| M | Mute |
| Esc / P | Pause |

Everything in the game — the city, characters, vehicles, names, story, art, sound and music — is original, made for this entry. Nothing from Rockstar Games or any other commercial game.
